# 雨夜 · 东北烧烤店微缩模型

[打开在线版](https://yangxiaoyang8.github.io/rainy-ne-bbq-miniature/) · [查看源码](https://github.com/yangxiaoyang8/rainy-ne-bbq-miniature)

一座可旋转的双层东北烧烤店：一楼是炭火、啤酒与旧海报，二楼有包间和外侧楼梯。墙面采用做旧贴图，街道有路灯、雨雪和随季节变化的树。

玩法：拖动旋转、滚轮缩放；分别开关招牌灯与室内灯；切换一楼/二楼、室外/室内、春夏秋冬、晴雨雪和白天/黄昏/夜晚。“回到门前”可重置楼层与视角。

本地运行：在仓库目录执行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。Three.js 从 CDN 加载，首次访问需要联网。

喜欢这个小店的话，可以点仓库右上角的 **Star** ⭐。
